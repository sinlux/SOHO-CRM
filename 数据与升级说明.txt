SINLUX CRM - 数据、隐私与升级说明

一、你的数据放在哪里
全部在程序文件夹下的 data 文件夹里（数据库 crm.db、图片、供应商聊天截图、备注截图、导出的 PDF/Excel、备份）。
程序不会把这些内容上传到任何地方。

二、升级会不会动我的数据 / 设置 / API Key？
不会。升级包只允许改动 app 文件夹（程序本身）和根目录的 .bat/.txt 文件；
任何想改动 data 文件夹的升级包，程序会直接拒绝。
你填过的 DeepSeek / Tavily Key、汇率、公司抬头、收款信息、WhatsApp 模板、HS 查询网址等设置，
都保存在 data/crm.db 里，升级不会清空、不会重置。
数据库结构的变化只会"新增"（加列、加表），不会删除或改写你已有的内容。
如果某次升级确实必须改动你的某项设置，会在更新说明里写清楚，并先征得你同意。
每次升级和回退之前，程序都会自动把当前数据备份到 data/backups。

三、什么时候会联网
1) 汇率：读取中国银行牌价页（不发送你的任何数据）。
2) AI 背调：只有你点「AI 背调」时，才会把这个客户的公司名和国家发给搜索服务和 AI 服务。
   不想用就不要填 API Key，这个功能就完全不联网。
3) 抓取客户公开官网（背调时）。
除此之外不联网。聊天截图和备注截图的文字识别（OCR）使用 Windows 自带功能，在本机完成。

四、你需要自己注意的
- data 文件夹没有密码、没有加密。请不要放进公开的网盘同步目录；备份 zip 也请自己保管好。
- 定期点「设置 → 立即备份」，并把备份拷到另一个安全的地方。
