SINLUX CRM 5.0 验收清单（在你自己的 Windows 电脑上，用真实数据做一遍）

做法：先双击「启动.bat」。每做完一项在前面打个勾；遇到任何不对，截图 + 写下你点了什么、看到什么，发给我。
建议先备份：设置 → 立即备份（任何时候都可以点）。

【A. 启动与数据】
[ ] 1. 双击启动.bat，浏览器自动打开，首页是「数据看板」
[ ] 2. 设置 → 版本与升级：显示的版本号是你拿到的版本
[ ] 3. 设置 → 立即备份：生成一个 zip（data/backups 里能看到）

【B. 客户】
[ ] 4. 导入客户：用你真实的客户 Excel 导入（先预览再确认），数量对得上
[ ] 5. 录入一个新客户、给它写备注、贴一张截图（Ctrl+V）、加一条提醒
[ ] 6. 客户详情页点「AI背调」（需要 DeepSeek/Tavily Key），结果要你确认后才写入

【C. 产品】
[ ] 7. 导入产品：拿你真实的产品 Excel（最好含图片）走完 5 步向导，图片位置对、数据对
[ ] 8. 产品库里打开一个产品：图片是居中白底高清图、SKU 规则符合预期、价格历史正常
[ ] 9. 设置 → 汇率：点「立即从中国银行更新」，看是否成功；失败请把页面上的红字发给我

【D. 报价】
[ ] 10. 新建一张报价单（选客户、加产品、改价格），金额算得对
[ ] 11. 导出 PDF：字体好看、LOGO 清晰、中文能正常显示、Payment Information 正确
[ ] 12. 导出 Excel：金额是公式，改数量合计会变
[ ] 13. 标记成交：客户阶段变成「成交」，产品页多一条售价历史

【E. PI 与旧数据】
[ ] 14. 导入 PI：用你真实的两张 PI (.xls)，产品/成本/客户匹配都对
[ ] 15. （如果还需要）双击「迁移旧数据.bat」迁移旧 QuoteMaster，迁移报告里没有异常

【F. 升级与回退（最后做）】
[ ] 16. 设置页能看到升级区域；之后我给你的第一个小升级包，用它升级一次，再回退一次，数据都还在

全部勾完且没有问题后，告诉我，我们就锁定 5.0.0 正式版。
